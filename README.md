# 🍔 FlavorHub – Modern Restaurant & Online Food Ordering Frontend

FlavorHub is a fully responsive, feature-rich modern web frontend for a restaurant and online food ordering platform. Built with **Tailwind CSS**, **Font Awesome**, and vanilla **JavaScript**, it provides a complete simulated e-commerce and dining experience directly in the browser.

---

## ✨ Key Features & Functionality

*   **1. Comprehensive Menu Marketplace:**
    *   Browse over 70+ handcrafted culinary items categorized across 10 distinct sections (Starters, Soups & Salads, Indian Veg & Non-Veg, Biryani, Pizzas, Burgers, Pasta, Desserts, and Beverages).
    *   Dynamic real-time search and category filtering chips.
    *   Advanced dietary toggles (Vegetarian, Non-Vegetarian, Vegan, Gluten-Free).
    *   Sorting options by price, rating, and featured status.
*   **2. Custom Combo Meal Builder:**
    *   An interactive 4-step builder allowing customers to pick a Main, Side, Beverage, and Dessert.
    *   Automatic calculation of bundle discounts (15% OFF) with real-time price updates.
*   **3. Smart Food Recommendation Engine:**
    *   Rule-based recommendation tool where users can filter by dietary preference, spice tolerance, budget, and meal type to find their ideal dish.
*   **4. Interactive Cart & Checkout System:**
    *   Slide-out cart drawer with item quantity adjustments and custom cooking instructions.
    *   Working coupon code support (`FLAVOR10`, `WELCOME50`, `FLAVOR20`).
    *   Simulated checkout supporting Home Delivery or Store Pickup, and multiple payment options (COD, UPI, Credit/Debit Card).
    *   Instant order confirmation modal with printable receipt generation.
*   **5. Table Reservations:**
    *   Online table booking form with instant reference ID generation and local storage logging.
*   **6. Interactive Gallery & Lightbox:**
    *   Filtered photo gallery of food, ambience, and desserts with full-screen lightbox navigation.
*   **7. Customer Reviews & Testimonials:**
    *   Read existing reviews or submit a new review with star ratings.
*   **8. Customer Account & Dashboard:**
    *   Simulated user authentication and profile dashboard tracking past demo orders and table reservations.
*   **9. Dark / Light Mode Support:**
    *   Persistent light and dark theme toggling using Tailwind CSS.

---

## 🛠️ Technology Stack

*   **HTML5 & CSS3** (Semantic markup and custom styling)
*   **Tailwind CSS** (v3 via CDN with custom theme extensions)
*   **JavaScript (ES6+)** (Dynamic rendering, state management, and interactivity)
*   **Font Awesome (v6.4.0)** (Icons)
*   **Google Fonts** (Inter & Playfair Display typography)
*   **LocalStorage API** (Persistence for cart items, favorites, orders, reservations, and user profiles)
